# Business Model 1 — Trades Growth System

A productised service for small carpentry businesses (2–8 staff), starting in the UK.

**The promise to the client:** less admin, faster quotes, paid on time, and more of the right jobs coming in.

**The promise to Aaron:** one repeatable system, delivered the same way for every client, so time goes on winning clients rather than reinventing the work.

---

## The model at a glance

| | |
|---|---|
| **Who** | Owner-run carpentry/joinery firms, 2–8 staff, UK first |
| **What** | Set up their bookings, quoting and invoicing system, Google profile, reviews and (if needed) a website — then keep it running each month |
| **How it's sold** | £1,000 one-off setup → monthly retainer (£250 Care or £500 Growth) |
| **How it's delivered** | A fixed 14-day playbook, the same for every client |
| **Time available** | ~15 hours/week (~60 hours/month) |
| **Target** | £2,000/month consistently, then scale |

## Roadmap

1. **Weeks 1–2 — Get ready.** Pick and learn one job-management tool. Build the website template. Finalise the intake form and a simple contract.
2. **Weeks 3–6 — Founding clients.** Sign 2 people you already know at a founding price in exchange for a testimonial and before/after numbers.
3. **Weeks 7–12 — Full price.** Use the case studies to sign clients at £1,000 setup, moving each into a retainer.
4. **Month 4+ — Scale.** Referral scheme, then consider paid ads for yourself once retainers cover the cost.
